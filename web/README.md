# The Capital — сайт и админка

Сайт кальянной The Capital (Ереван) на Next.js. Весь контент — тексты, картинки,
меню, навигация — лежит в базе и правится прямо на сайте, без правки кода.

Дизайн перенесён один в один из макетов Claude Designer, которые лежат в корне
репозитория (`The Capital.dc.html`, `Menu.dc.html`, `Visit.dc.html`). Макеты
остаются источником оформления: если появится новая секция, её удобно сначала
нарисовать там, а потом перенести сюда.

## Запуск

```bash
npm install
npm run db:push     # создать таблицы
npm run db:seed     # залить контент из макетов
npm run dev         # http://localhost:3000
```

Вход в админку — `/admin/login`, учётка берётся из `.env`
(`ADMIN_EMAIL` / `ADMIN_PASSWORD`, по умолчанию `admin@thecapital.am` / `capital`).
Пароль меняется в админке в разделе «Настройки».

## Как редактируется сайт

1. Войти в `/admin`.
2. Открыть страницу с параметром `?edit=1` — или нажать «Править RU/EN» в админке.
3. Кликнуть по любому тексту и печатать. `Enter` — сохранить, `Esc` — отменить.
   В многострочных полях сохранение по `Ctrl`/`Cmd + Enter` или клику мимо.
4. На картинку перетащить файл или нажать и выбрать. Кнопка «кадр» двигает
   видимую часть фото, «вписать/заполнить» меняет режим вписывания.
5. У списков (цифры, теги, карточки, отзывы, часы, правила, позиции меню)
   при наведении появляются стрелки порядка и крестик удаления,
   рядом — кнопка добавления.
6. Языки правятся раздельно: переключатель EN/RU в шапке.

Цены в меню хранятся числом, а «5 000 ֏» / «5,000 ֏» дорисовывается при выводе
по языку. Поэтому в режиме правки в поле цены видно голое число. Кнопка «от»
включает формат «от 9 000 ֏».

## Что где лежит

```
prisma/schema.prisma        структура базы
prisma/seed.ts              исходный контент (перенесён из .dc.html)
src/lib/content-schema.ts   какие есть тексты, списки, слоты картинок, настройки
src/lib/content.ts          чтение контента из базы
src/lib/view.ts             типы и хелперы вывода (безопасны для браузера)
src/lib/actions.ts          server actions редактора
src/lib/auth.ts             сессии на JWT в httpOnly-куке
src/components/editor/      механика правки: Editable, Slot, Repeat, панель
src/components/site/        страницы сайта — вёрстка из макетов
src/app/[lang]/             публичные страницы (/en, /ru)
src/app/admin/              админка
src/app/api/upload/         приём картинок (сжатие в webp)
```

Новый редактируемый блок добавляется так: описать его в `content-schema.ts`,
добавить данные в `seed.ts`, вывести на странице через `<Txt>` / `<Repeat>` /
`<Slot>`. Отдельная админка для него не нужна — правка появится сама.

## Переезд на хостинг

Сейчас база — SQLite в файле `dev.db`, картинки — в `public/uploads`.
Для продакшена:

1. `prisma/schema.prisma` → `provider = "postgresql"`, в `.env` — строка
   подключения к Postgres (Neon, Supabase, свой сервер). Схема совместима,
   переписывать модели не нужно.
2. В `src/lib/db.ts` заменить адаптер `@prisma/adapter-better-sqlite3`
   на `@prisma/adapter-pg`.
3. `AUTH_SECRET` — обязательно новый:
   `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.
4. Если хостинг без постоянного диска (Vercel), картинки переводятся в облачное
   хранилище — правится только `src/app/api/upload/route.ts`, всё остальное
   работает через путь из таблицы `Media`.
5. Сменить пароль администратора и удалить дефолтную учётку.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер |
| `npm run build` | Продакшен-сборка |
| `npm run start` | Запуск собранного |
| `npm run db:push` | Применить схему к базе |
| `npm run db:seed` | Залить исходный контент (не затирает правки) |
| `npm run db:reset` | Снести базу и залить заново |
| `npm run db:studio` | Prisma Studio — таблицы глазами |
